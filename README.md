# UNP_ML_CLASSIFICATION_PROJECT_CREDIT_CARD_RISK_PREDICTION_USING_PYTHON


I did this project in collaboration with United Network Of Professionals (UNP) on Credit Card Risk Prediction Using Python.This is a group project completed as part of our internship.

This project focuses on predicting whether a credit card application will be Approved or Rejected using machine learning. It uses a dataset containing 690 records with applicant-related information. The main aim is to understand applicant details and predict credit card approval outcomes. Data cleaning and preprocessing are performed to prepare the dataset for analysis. Exploratory Data Analysis is used to identify patterns and relationships in the data. Eight machine learning algorithms are implemented and compared using different train-test splits. An Artificial Neural Network (ANN) is also developed and evaluated with different configurations. Model performance is compared using accuracy, precision, recall and F1-score. The project also gives importance to identifying applications that may be rejected. The results help understand how machine learning can support credit card approval and risk assessment.

Technologies Used: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, TensorFlow and Keras.
